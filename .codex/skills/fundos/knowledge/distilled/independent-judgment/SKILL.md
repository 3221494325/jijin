# 独立判断：决策权不外包（independent-judgment）

## R — 原文 (Reading)

> "I know from experience that nobody can give me a tip or a series of tips that will make more money for me than my own judgment. It took me five years to learn to play the game intelligently enough to make big money when I was right. ... Instead of standing or falling by my own observation and deductions I was merely playing another man's game."
>
> 译文：以我的经验，没有人能给我一条或一串小道消息，比我自己的判断更能赚钱。我花了五年才学会聪明地玩这个游戏，在自己对的时候赚大钱。……我不再靠自己的观察与推理立足或倒下，我只不过是在玩别人的游戏。
>
> — Livermore，第3章（f07；另见 p09"我不相信小道消息，靠 Smith 的消息买入就必须靠 Smith 的消息卖出"；p12"盘口不讲究情面，也不奖励忠诚"）

---

## I — 方法论骨架 (Interpretation)

独立判断不是"信息隔离"，而是**决策权不外包**。消息、大V、内幕、权威、人情——任何外部来源都只能作为输入，必须经过你自己可复核的证据链验证后，才能影响仓位。

核心逻辑是一条锁链：**依赖别人买入，就等于依赖别人卖出**——买点由对方决定，卖点就不在你手里，资金命运被交了出去。书中反复出现的三种"被绑架"模式：

1. **权威压力**——消息灵通且动机"善良"的人劝你反手（Saratoga 联合太平洋事件）；
2. **魅力说服**——口才与"独家数据"让你从确定变成犹豫（Percy Thomas 棉花局）；
3. **人情感恩**——亏欠与关系让你交出决策权（Williamson 人情账户）。

检验标准只有一条：外部建议若无法回答"我凭什么信它、它服务于谁、错了谁能负责"，就不进入决策。最终裁决只交给可复核的价格行为与自己的规则。

## A1 — 书中的应用 (Past Application)

### 案例 1: Saratoga 联合太平洋——权威朋友的电话（c04/x03）
- **问题**: 他从盘面读出联合太平洋正被"聪明钱"吸筹并一路加仓；消息灵通的好友 Ed Harding 打长途警告"内线正在把货倒给你"。
- **方法论的使用**: 没有用价格行为复核，而是接受权威观点，清掉多头并反手在 162 附近做空 4,000 股——"既然不该做多，就该做空"。
- **结论**: 他承认"我按了他的建议做了"，却解释不了为什么放弃自己多年训练的盘面判断。
- **结果**: 次日 UP 董事会宣布 10% 股息，股价跳涨创历史新高，空头被彻底打爆，两头挨打。

### 案例 2: Percy Thomas 棉花局——魅力专家与"独家数据"（c07/x04）
- **问题**: 他原本看空棉花且持有空单；棉花大佬 Thomas 带着"南方一万名通讯员的独家数据"反复游说。
- **方法论的使用**: 他无法反驳数据的真实性，于是"不再用自己的眼睛看市场"：先平空单，又因"错了就必然反着做"的思维定式反手做多。
- **结论**: "一个人无法被说服反对自己的信念，却能被谈进犹豫不决的状态，那更糟"——从自信变成犹豫，决策权已外包。
- **结果**: 棉花头寸累计亏损数十万美元（其中一笔收盘前追买约亏 40 万），并连锁拖入 Williamson 人情账户困局。

### 案例 3: Williamson 人情账户——感恩绑架决策权（c08/x05）
- **问题**: 破产后券商 Williamson 借他本金、替他"填补"亏损，随后以"我知道这家公司的内情"为由让他平掉正确的空头、反手做多。
- **方法论的使用**: 他因感恩放弃判断照做，甚至彻底交权——"别自己交易，我来替你赚回来"。
- **结论**: "把我的判断屈从于他的意愿，是我的败因；盘口不讲究情面，也不奖励忠诚。"
- **结果**: 亏掉全部利润还欠券商 15 万美元，且被用作掩护他人出货的"烟幕"，错失 1911-1914 四年最大机会。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户收到"内幕消息 / 群友喊单 / 大V荐基 / 理财经理推荐"，问要不要跟；
2. 用户因朋友、渠道或人情关系想改变持仓方向，且理由主要是"别人让我买"；
3. 用户被权威观点动摇，在"听他的还是听自己的"之间纠结；
4. 用户复盘时发现某次操作是"因为听了别人的建议"，想建立防再犯机制。

### 语言信号（用户的话里出现这些就应激活）

- "要不要跟" / "大V说" / "朋友推荐我买" / "有内幕消息" / "听说要涨" / "该听谁的"
- "理财经理推荐" / "内部渠道" / "群友喊单" / "follow tips" / "insider tip" / "该不该信他"

### 与相邻 skill 的区分（初稿，阶段3回填）

- 与 `herd-contagion-check`（EPD）: 后者处理"群体都在做所以我也要做"的从众；本技能处理"某人直接给你的建议"。群友晒收益引发跟风→从众；群友信誓旦旦推荐→本技能。
- 与 `narrative-news-check`（EPD）/ `deep-news`（FundOS）: 后者核查新闻事实与叙事逻辑；本技能不判断消息真假，只判断"这个外部观点要不要进入我的决策链"。
- 与 `price-action-first`: 本技能在决策链入口过滤"信源"，后者在末端用"价格行为"裁决"解释"，两者可串联。

## E — 可执行步骤 (Execution)

当 skill 被激活后，按以下步骤执行:

1. **拆分外部观点（事实 / 观点 / 动机）**
   - 把每条外部建议拆成：主张是什么、依据是否可复核、说话者与持仓/佣金有无利益关系。
   - 完成标准: 输出三栏对照表，能回答"我凭什么信它、它服务于谁"。
   - 判停条件: 若来源无法复核或利益冲突明显 → 直接降为"背景信息"，跳到步骤 4。

2. **独立证据核验**
   - 用价格行为、资金流、公开基本面数据检验主张是否被市场行为支持。
   - 完成标准: 写出一条明确的"市场行为支持 / 不支持"结论。

3. **规则触发而非建议触发**
   - 问: 这个操作触发我哪条预设规则（止损线 / 加仓条件 / 仓位上限）？
   - 完成标准: 动作能对应到自己的规则；对应不上 → 不做。

4. **留痕复盘**
   - 写入 trade_journal: 信息来源、验证结果、最终决策。
   - 完成标准: 每次调用至少新增一条带"信息来源"标签的记录，供日后复盘同类情境。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只问"这条新闻是真是假" → 用 `narrative-news-check` / `deep-news` 做事实核查；
- 用户问"大家都在买，我该不该跟上" → 用 `herd-contagion-check` 做从众分析；
- 用户在算具体止损/仓位数值 → 用 `stop-loss-admission` / `right-side-entry-pyramid`。

### 作者在书中警告的失败模式

- **tip 上瘾**（x02/g07）: 靠内幕 tip 破产比饥荒瘟疫更快；求 tip 者要的不是好 tip，而是任何 tip（贪欲+虚荣驱动）。
- **权威朋友劝阻**（x03）: 自己判断正确，却被"消息灵通的好友"劝反手，次日被打爆。
- **魅力说服**（x04）: "一个人无法被说服反对自己的信念，却能被谈进犹豫不决的状态，那更糟"。
- **人情绑架**（x05）: 感恩与关系驱动决策，错失四年最大机会。
- **sucker 模式**（g13）: 想要不劳而获、拒绝思考、依赖他人建议——聪明人只要行为符合这个模式就是 sucker。

### 作者的盲点 / 时代局限

- 1920s 美股无证监会、内幕横行；作者反的是"依赖"而非"信息"本身——他后半生也参与做庄与操纵，独立判断不等于道德清高。
- 现代监管大幅压缩内幕空间，但"动机不透明"的荐购、带货、返佣依然普遍，本检验框架仍然适用。
- 另一面: 过度"独立"也可能变成固执；本技能不要求拒绝所有信息，只要求"可复核 + 决策权自持"。

### 容易混淆的邻近方法论

- `price-action-first`: 信源过滤 vs 价格裁决——本技能先做，后者殿后；
- EPD 从众检验: 个人被建议 vs 群体行为——语言信号不同，勿互相抢调用。
