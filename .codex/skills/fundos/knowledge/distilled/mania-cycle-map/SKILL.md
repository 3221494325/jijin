## I — 方法论骨架 (Interpretation)

狂热不是一步到位，密西西比（1716–1720）、南海（1720）、郁金香（1634–1637）三大案例共享同一条可观察的周期：

1. **起源**：新故事或制度创新点燃想象（纸币信用、南美金银矿、异域花卉）；
2. **杠杆放大**：信贷、纸币、期货等工具把涨幅推离基本面；
3. **赚钱效应扩散**：从众传染，先入场者晒收益，后知后觉者焦虑跟进；
4. **全民参与**：从不碰金融的人也入场，增量接盘资金枯竭；
5. **崩溃**：任何微小信用事件（挤兑、法案、违约）触发崩塌，且"永不再回到狂热价位"。

冰宫比喻强调：建筑越辉煌，离融化越近。定位周期的意义在于先判"现在在哪一段"，再决定持有、减仓还是不参与；切忌把"还在涨"当作"周期未到顶"的证据。

## A1 — 书中的应用 (Past Application)

### 案例 1: 密西西比"冰宫"从辉煌到融化（1716–1720）
- **问题**: 约翰·劳的纸币信用体系让法国财政"起死回生"，股价一路狂飙，全民认购。
- **方法论的使用**: 沿周期逐段对照——起源（纸币创新）→杠杆（股价越高越增发纸币）→全民参与（各阶层都在炒）→崩溃（挤兑一来，整座"冰宫"融化）。
- **结论**: 周期越到后段，价格越依赖增量资金与信用，与真实盈利无关。
- **结果**: 挤兑后纸币与股价同时崩塌，法国金融瘫痪多年，"没有谁能再把它扶起来"。

### 案例 2: 郁金香从收藏品到"永不再涨"的天价球茎（1634–1637）
- **问题**: 单株球茎可换豪宅加十二英亩土地，主要买家从"观赏收藏"变成"转手赚差价"。
- **方法论的使用**: 用价格-价值脱钩三问检验——上涨靠真实盈利还是再售差价？持有者多还是倒手者多？价格能否被任何基本面解释？
- **结论**: 一旦"总有人要亏大钱"的怀疑扩散，价格崩塌且永不再回到狂热价位。
- **结果**: 荷兰法院拒绝受理郁金香契约，赌债在法律上不算债；周期以全民财富蒸发收场。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 持仓板块/基金连涨后，用户问"还能追吗""要不要先落袋"；
2. 用户怀疑某热门板块"是不是泡沫/过热"，想定位它在狂热周期中的位置；
3. 复盘时想把"我为什么亏/赚"归因到周期阶段，检验加减仓时机。

### 语言信号（用户的话里出现这些就应激活）

- "涨太多了" / "还能上车吗" / "是不是泡沫"
- "这个板块到顶了没" / "要不要落袋" / "过热了吗"
- "现在追进去会不会接盘" / "我们处在哪一段"

### 与相邻 skill 的区分

- 与 `narrative-news-check` 的区别: 本 skill 回答"处在哪一段/过热没有"，新闻检查回答"这条消息值不值得信"；
- 与 `sector-rotation-detector` 的区别: 轮动识别回答"钱在往哪走"，本 skill 回答"这个方向已经走到第几段"；
- 与 `mass-participation-top` 的区别: 全民参与是周期第四段的一个子信号，本 skill 做完整四段定位，不只盯破圈度。

## E — 可执行步骤 (Execution)

当 skill 被激活后，按以下步骤执行：

1. **取全市场数据**
   - 执行: `python D:\基金项目\market_scan.py`（新浪源，东财push2限流不可用）
   - 完成标准: 拿到目标板块涨幅榜、成交额、换手；无成交额放大的单日脉冲标记为弱信号

2. **四段定位**
   - 用信号清单逐段核对：起源（有无新叙事/制度变化）→杠杆（融资余额、份额增速、信用指标）→全民（破圈度、热搜、新基发行）→崩溃前兆（挤兑/赎回/监管动作）
   - 完成标准: 输出"当前位于第 X 段"，并给出 2 条以上证据

3. **估值锚三问（价格-价值脱钩检验）**
   - 一问上涨靠真实盈利还是故事/再售差价；二问成交结构里长期持有者多还是短线倒手者多；三问价格能否被任何基本面解释（对照历史估值中枢）
   - 判停条件: 若价格仍能被盈利解释且无杠杆放大 → 判定为价值修复，跳转到第 5 步并提示"非狂热"

4. **对照持仓给动作**
   - 起源段 → 可小仓试探；杠杆/扩散段 → 持有但设离场规则；全民段 → 分批减仓（每次 ≤20%）；崩溃前兆 → 减仓/清仓，禁止追加
   - 完成标准: 对用户 8 只基金中的相关持仓给出明确动作与仓位上限（科技总仓 ≤40% 阈值）

5. **落地纪律**
   - 将减仓/止损/再平衡规则写入 `trade_journal.py add`，注明依据周期段位
   - 完成标准: 输出一条可回查的操作记录与离场触发条件

## B — 边界 (Boundary) ★

### 不要使用此 skill 的场景

- 用户只查单只基金净值 → 用 `fundos-core`；
- 需要"为什么涨"的深度原因 → 用 `narrative-news-check` / `deep-news`；
- 无持仓、纯理论讨论 → 不需要做仓位动作；
- 低估板块的正常价值修复（无杠杆、无破圈、涨幅可被盈利解释）→ 不属于狂热，不要误判。

### 作者在书中警告的失败模式

- 把"还在涨"当"周期未到顶"的证据——冰宫越辉煌离融化越近；
- 价格脱离价值后仍用"别人愿意出更高价"论证合理（反例 x06）；
- 狂热中没有任何人刹车，连创始人约翰·劳自己都忘掉"无准备金不印钞"的铁律（反例 p08）。

### 作者的盲点 / 时代局限

- 19 世纪叙述文学，无量化数据（无市盈率、无成交量统计）；
- 郁金香"全民参与"程度后世有争议（Peter Garber 修正观点，经济影响可能被夸大）；
- 作者假设"群体永远错、少数清醒者永远对"——实际泡沫中离场过早也会踏空巨亏；
- "这次不一样"有时是对的（铁路、互联网、AI 确实改变价值锚），只用历史类比可能错过真正长期趋势。

### 容易混淆的邻近方法论

- "涨幅大" ≠ "狂热"：要看杠杆、参与结构、估值锚三合一；
- "热点" ≠ "周期后段"：短期情绪脉冲可能是起源段而非见顶段。
