## I — 方法论重构

市场每天都在轮动：资金从旧主线撤出，涌入新主线。判断市场主线是组合管理的核心能力，因为**押对主线的人吃肉，押错的人只喝汤**。

识别主线 = 回答三个问题：
1. **谁在涨**（涨幅榜）— 全市场224个板块的涨幅排名
2. **钱在哪**（资金榜）— 主力净流入排名（有资金推动的上涨才可持续）
3. **持续性**（动量）— 该方向是否连续多日走强，还是单日脉冲

持仓板块与市场主线的关系决定了组合相对表现：
- 持仓 = 主线 → 吃肉，保持仓位
- 持仓 ≠ 主线 → 落后，需要切换或对冲
- 主线已涨太多（拥挤）→ 警惕回调，不追高

关键纪律：**先看全市场，再诊断持仓**。顺序反了就会被自己的持仓锚定，看不见真正的机会。

## A1 — 过去的应用(实战案例)

### 案例1: 科技vs医药主线切换(2026-08-03~07)
- **问题**: 用户持仓42-48%科技，但全市场最强方向是医药(CXO +11.6%)
- **方法论的使用**: 跑market_scan.py扫描224板块，对比持仓板块排名
- **结论**: 科技排中游(电子信息+0.9%)，医药登顶(CXO +11.6%)
- **结果**: 识别出风格错配1.3pp/日，给出"回本后切向医药"的建议

### 案例2: 光伏次线反弹(2026-08-07)
- **问题**: 华夏绿电连续走弱(-5%)
- **方法论的使用**: 扫描发现光伏新技术(BC/TOPCon/钙钛矿+5~6%)反弹启动
- **结论**: 绿电并非死局，光伏新技术是催化剂
- **结果**: 建议持有等回本，而非割肉

## E — 可执行步骤

当skill被激活后，按以下步骤执行:

1. **跑市场扫描**
   - 执行: `python D:\基金项目\market_scan.py`
   - 完成标准: 获得全市场行业/概念板块涨幅榜
   - 数据源: 新浪板块(稳定)，东财push2不可用

2. **识别主线**
   - 看涨幅榜TOP3 + 概念榜TOP5
   - 完成标准: 确定1-2个资金主攻方向
   - 判断信号: 涨幅>3%且成交额放大 = 强主线；单日脉冲无成交 = 假信号

3. **对比持仓**
   - 把用户持仓板块在全市场排行中的位置找出来
   - 计算: 持仓板块平均涨幅 vs 前5行业平均涨幅
   - 完成标准: 得出落后/领先的百分点

4. **给出建议**
   - 持仓在主线上 → 持有/加仓
   - 持仓落后 → 给出切换方向+分批节奏(每次≤20%)
   - 主线拥挤(涨幅>10%单日) → 提示不追高，等回调

## B — 边界

### 不要在以下情况使用此skill

- 用户只查单只基金净值 → 用fundos_core
- 需要"为什么涨"的深度原因 → 用deep-news
- 用户没持仓、纯理论讨论 → 不需要扫描

### 实战中发现的失败模式

- 单日脉冲涨幅≠主线：某板块单日+5%但无资金流入，次日就熄火
- 只看涨幅榜会被小市值板块误导：成交额<10亿的板块波动大、不可靠
- 东财数据源限流导致扫描失败 → 必须用新浪源

### 容易混淆的相邻概念

- "热点"≠"主线"：热点是短期情绪，主线是资金持续流入的方向
- "涨幅"≠"强度"：要看涨幅+资金流+持续性三合一
