# 安全边际：好货打折才买

## R — 原文 (Reading)

> "Simply put, we feel that if we can buy small pieces of businesses with satisfactory underlying economics at a fraction of the per-share value of the entire business, something good is likely to happen to us - particularly if we own a group of such securities."
>
> — 巴菲特, 1984 年致股东信
>
> "Price is what you pay; value is what you get. Whether we're talking about socks or stocks, I like buying quality merchandise when it is marked down."
>
> — 巴菲特, 2008 年致股东信

---

## I — 方法论骨架 (Interpretation)

安全边际 = 好生意 + 显著低于内在价值的价格：以"买整家企业"的标准买碎股，折扣是对判断失误的缓冲（1984）。价格是你付出的，价值是你得到的（2008）：买卖必须同时回答"值多少"与"现价多少"两个问题，先确认是优质商品，再等折扣价。

便宜不等于安全边际：困境反转很少反转（1979）；困难企业"厨房里从来不止一只蟑螂"，初始便宜会被低回报快速侵蚀（1993）——这就是价值陷阱。质量优先：合理价格的好企业优于便宜价格的平庸企业（1979/1989）；错过好企业只是机会成本，买错坏企业是本钱损失。

市场越热，安全边际越薄（1997 年信警告当时股价已"实质性侵蚀安全边际"），越应降低仓位而非加码。对基金：建仓前先问"若这是整块资产我愿意付多少"，只在显著折价时出手；分批执行，用仓位而非预测保护自己。

## A1 — 书中的应用 (Past Application)

### 案例 1: GEICO 均价 $6.67（1976-1980）
- **问题**: 1970 年代 GEICO 濒临破产、股价暴跌，市场把好生意当成坏消息。
- **方法论的使用**: 确认低成本直销模式（好生意）后，在股价仅为整家企业每股价值一小部分时买入——"好事大概率发生"。
- **结论**: 好生意+好价格=安全边际；1984 年企业价值增长而股价停滞，也不动摇长期判断。
- **结果**: 至 1987 年底账面市值 $756.9M，1993 年底 $1.76B，1996 年现金全资。

### 案例 2（反面）: 雪茄烟蒂与纺织厂（1993/2024）
- **问题**: 便宜买入平庸生意——1965 年买下注定灭亡的纺织厂。
- **方法论的使用**: 事后总结"除非你是清算人，这种买法很蠢"：便宜价并非真便宜，问题层出不穷，初始优势被低回报侵蚀。
- **结论**: 价格低不等于价值高；安全边际必须质量+价格双重确认。
- **结果**: 纺织厂"折磨了我们二十年"，机会成本巨大。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "板块/基金跌了 40%，要不要抄底？"——先验证资产质量，再看折价是否显著。
2. 建仓/加仓前问"现在这个价能买吗？"
3. 看到打折基金/高收益债/困境反转题材时。

### 语言信号 (用户的话里出现这些就应激活)

- "抄底"、"跌了很多是不是便宜"、"低估了"、"PE 很低"、"打折"
- "安全边际"、"值不值得买"、"现在能上车吗"
- "margin of safety" / "bargain" / "cheap" / "value trap"

### 与相邻 skill 的区分

- 与 `intrinsic-value-ruler` 的区别: 标尺回答"值多少"，本 skill 回答"留多少缓冲才出手"；本 skill 依赖前者先给区间。
- 与 `mr-market-panic-buying` 的区别: 恐慌提供打折的时机，本 skill 提供打折的资格——恐慌时不买没有安全边际的资产。
- 与 `circle-of-competence` 的区别: 圈外再便宜也不碰；圈内才谈价格。
- 与 `mania-cycle-map`（EPD 系）的区别: 狂热周期里"贵还能更贵"会侵蚀安全边际；本 skill 要求狂热期降低仓位而非追价。

## E — 可执行步骤 (Execution)

当 skill 被激活后，按以下步骤执行:

1. **先圈后价**
   - 确认标的是否在能力圈内（能否回答现金流三问）；看不懂 → 转 `circle-of-competence`，一票否决
   - 完成标准: 明确写出"看得懂/看不懂"结论

2. **估算内在价值区间**
   - 用 `intrinsic-value-ruler` 方法输出三档区间（低估/合理/高估）
   - 完成标准: 每只候选基金有区间，无精确点位

3. **计算折价与安全边际**
   - 折价率 =（区间中枢 - 现价）/ 区间中枢；折价 ≥ 20-30% 才考虑建仓，折价 < 10% 不追加
   - 完成标准: 数字化结论
   - 判停条件: 基本面恶化（逻辑证伪）→ 任何折价都不买（价值陷阱/纠错纪律）

4. **排除假便宜**
   - 一票否决清单: 靠"困境反转"讲故事、EBDIT 式会计口径、杠杆/复杂结构、管理层从不认错
   - 完成标准: 清单逐项打勾

5. **分批执行 + 留痕**
   - 单次加仓 ≤ 单笔预算 20%，分 2-3 批；`python trade_journal.py add` 记录理由与预期
   - 完成标准: journal 有记录，留有现金应对继续下跌

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 资产质量未确认的"抄底"（先过 circle-of-competence）
- 用户只问"便不便宜"没问"值不值"——先转 intrinsic-value-ruler
- 短期博弈、支撑位、预测底部
- 基本面已恶化/逻辑证伪的标的（转纠错纪律 b08）

### 作者在书中警告的失败模式

- 价值陷阱/雪茄烟蒂（1993: 厨房里从来不止一只蟑螂）
- 会计炼金术（1989: EBDIT 出现就"拉上钱包拉链"）
- 困境反转很少反转（1979）
- 市场过热侵蚀安全边际（1997）

### 作者的盲点 / 时代局限

- 低估可能长期不修复（价值陷阱），巴菲特对此着墨不足
- "等待价格回归"在美股长牛中容易，在新兴市场可能等很多年
- 浮存金模式不可复制，散户的"弹药"有通胀成本（1979）

### 容易混淆的邻近方法论

- "跌得多" ≠ "便宜"
- "PE 低" ≠ "安全边际"
- 安全边际 ≠ 抄底点位预测
