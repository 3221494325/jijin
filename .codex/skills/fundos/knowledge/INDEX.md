### 关系说明（关键组合）
- **止损(r03) + 拿住(r04)** = 截断亏损、让利润奔跑，对称纪律。
- **叙事检验(e02) + 价格行为优先(r06)** = 新闻利好利空双闸门：先拆叙事，再等价格确认。
- **恐慌买入(b03) + 安全边际(b02) + 能力圈(b04)** = "大跌时敢买"三条件：好资产、好价格、看得懂。
- **狂热周期(e01) + 全民参与(e03)** = 判断板块过热的两只眼睛：周期定位 + 破圈度监测。
- **及时纠错(b08) + 止损(r03)** = 逻辑证伪触发纠错，价格破位触发止损，双轨离场。
- **不做清单(b07) + 杠杆放大器(e05)** = 杠杆类产品先过一票否决，再谈其他。
- **仓位框架(b06) + 主线轮动(sector-rotation)** = 结构上不伪分散，方向上跟上主线。
- **巴菲特视角(buffett-perspective) + 内在价值(b01) + 安全边际(b02)** = 人格顾问给方向，框架技能给数值，组合使用。

## 使用顺序建议（按用户场景）
1. 每日盘中：sector-rotation-detector（主线）→ fundos 组合诊断 → 持仓分析
2. 有新闻事件：narrative-news-check（拆三层）→ price-action-first（等价格确认）
3. 想加仓：mania-cycle-map（周期定位）→ margin-of-safety（估值）→ right-side-entry-pyramid（分批）
4. 想减仓/止损：mass-participation-top（过热）→ stop-loss-admission（纪律）→ timely-correction（逻辑）
5. 情绪波动：emotion-discipline-system（先停手）→ 再回到以上流程
