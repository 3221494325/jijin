# 阶段 1.5 — 三重验证筛选（《非同寻常的大众幻想与群众性癫狂》）

> 候选池：frameworks(8) + principles(8) + cases(6) + counter-examples(6) + glossary(8) = 36 条 → 去重合并为 7 个方法论单元 → 三重验证后通过 5 个。

## 通过单元（将进入阶段 2 构造 skill）

### e01 狂热周期律 + 泡沫识别（起源→杠杆→全民参与→崩溃）
- type: framework
- 来源候选: f01, f02, p04
- V1_cross_domain: ✅ 密西西比(1716-1720)、南海(1720)、郁金香(1634-1637) 三案例时间线完全同构，冰宫比喻(palace of crystals)与郁金香"never rose again"双重印证；作者还预言1825泡沫公司潮、1845铁路狂潮(p06)同一配方换壳重演。
- V2_predictive_power: ✅ 新问题"热门板块还在涨要不要追？"→ 推导：先定位周期阶段(起源/杠杆放大/全民参与/接盘枯竭)，凡处于全民参与段则减仓不追；把"还在涨"从买入理由降级为周期信号。
- V3_exclusivity: ✅ "价格锚从内在价值切换到再售差价的那一刻，崩塌只是时间问题"——反直觉：涨得越热闹越接近终点。
- 备注: 与 b02 安全边际构成"泡沫识别(市场端)+估值纪律(资产端)"互补；p04"买来转手"是泡沫识别核心判据。

### e02 叙事/故事驱动定价（利好新闻三层检验）
- type: decision-framework
- 来源候选: f04, p02
- V1_cross_domain: ✅ 南海"秘鲁港口谣言→股价大涨"；"从事重大事业但没人知道是什么"的公司五小时募一千股；密西西比靠"路易斯安那遍地金银"故事。至少3个独立语境。
- V2_predictive_power: ✅ 新问题"利好新闻满天飞要不要加仓？"→ 推导：拆三层(事实/叙事/杠杆)——只有叙事没有事实兑现的上涨不能作为加仓依据；利好出尽=叙事兑现、无人接力之时。
- V3_exclusivity: ✅ "定价的不是事实，而是金锭在眼前跳舞的想象"——把新闻解读从"找利好"变成"拆叙事"，直击散户追消息通病。
- 备注: 与 r06 价格行为优先构成"新闻检验(信息端)+价格确认(市场端)"双闸门；是 FundOS 新闻利好利空判断流程的核心方法论。

### e03 全民参与 = 顶部信号（破圈度监测）
- type: decision-framework
- 来源候选: f06, p01
- V1_cross_domain: ✅ 郁金香(仆人/扫烟囱/收旧衣者进场)、密西西比("每个年龄、性别、阶层的人都在炒股票")、南海("整个国家都变成股票投机客") 三案例同现。
- V2_predictive_power: ✅ 新问题"从不理财的人也来问买什么基金"→ 推导：增量买家枯竭=接盘者耗尽，破圈度上升=减仓信号而非加仓信号；宁可少赚不接最后一棒。
- V3_exclusivity: ✅ "当所有可能的买家都已入场，价格只剩下跌一条路"——用社会参与度做顶部信号，反常识(多数人把"人气高"当利好)。
- 备注: 与 r05 独立判断(不跟风)和 e04 从众机制(为什么会传染)构成一组。

### e04 从众传染机制与智者亦随众（个体理性失效）
- type: mental-model
- 来源候选: f03, f08, p05
- V1_cross_domain: ✅ 拉莫特与神父泰拉松"发誓不碰→几天后交易所门口撞见对方在买"；imitativeness 总结段(成功催生同类项目)；1825/1845 换壳重演。至少3个独立语境。
- V2_predictive_power: ✅ 新问题"我很理性，不会被市场情绪影响"→ 推导：假设自己正在被传染是唯一安全假设；用事前写下的买入/卖出清单替代狂热中的临场判断。
- V3_exclusivity: ✅ "永远不要发誓你绝不会做某件蠢事"——任何人(包括自认聪明者)都可能随众，智力/专业/经验不能免疫。
- 备注: 与 r07 情绪管理制度化构成"为什么需要纪律+怎么设纪律"的完整链条。

### e05 杠杆与信用扩张：狂热放大器 + 崩溃放大器
- type: principle
- 来源候选: p03, p07(部分), f05(部分)
- V1_cross_domain: ✅ 密西西比"股价越高越增发纸币跟上"螺旋；南海议员布罗德里克"全国现金不过一千万、信用撑到两亿"；p08 劳和摄政王忘掉准备金铁律。至少3个独立语境。
- V2_predictive_power: ✅ 新问题"融资余额激增/杠杆资金涌入某板块"→ 推导：把杠杆视为脆弱性信号——涨时放大涨幅，跌时强制平仓连环放大回撤；带杠杆产品不应成为组合主力。
- V3_exclusivity: ✅ "螺旋的每一圈都在放大崩塌时的破坏力"——杠杆不是中性工具，是双向放大器；散户视角常只看到杠杆的进攻面。
- 备注: 与 b07 不做清单(杠杆一票否决)直接对接；是 FundOS 风险控制层的理论根基。
