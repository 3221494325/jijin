- **出版/发布时间**: 1977-2024（来源 ReeceHarding/buffett-letters，官方公开文本）

## 1. 结构 (Structural)
### 类型
价值投资实操手册：以伯克希尔几十年的真实买入/持有/回购/并购记录，展示"买企业所有权"的长期复利逻辑。

### 一句话主旨
买股票就是买企业所有权；只在能力圈内用合理价格买优秀企业，然后长期持有，让复利工作，并善用市场恐慌。

### 骨架（七大主题，贯穿各年份）
1. 衡量标准：内在价值 vs 每股账面价值；用"所有者盈余"看企业真实产出（1977/1983/1993）。
2. 好企业 vs 平庸企业：特许经营权/护城河企业，管理层资本配置能力（1983/1995）。
3. 资本配置：回购、并购、分仓；"用合理的价格买伟大的企业优于便宜买平庸企业"（1984/1989/1997/2014/2022）。
4. 市场先生：把市场波动当仆人而非向导；恐慌是机会（1987/2008）。
5. 风险观：杠杆、衍生品、通胀、预测他人——"不做"清单（2002/2005/2008/2016）。
6. 长期主义：持有期"永远"；复利需要时间（1991/2019/2024）。
7. 给普通人的建议：不选股的人应买低费率宽基指数基金并长期定投（1993/1996/2005 反复出现）。

**论点之间的关系**: 层层深入——先建立衡量标尺（1-2），再谈标的选择（3），再谈情绪与风险（4-5），落到时间维度（6），最后给出普通人可执行的降级方案（7）。

### 作者要解决的核心问题
如何在 50 年尺度上把资本配置做对：选什么、出什么价、拿多久、犯什么错不能犯。

## 2. 解释 (Interpretive)
### 关键术语
| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 内在价值 | 企业未来现金流折现的估计值 | 无法精确计算，只能"大致区间" |
| 所有者盈余 | 净利润+折旧摊销-维护性资本开支 | 比会计利润更接近真实现金流 |
| 特许经营权 | 能持续提价而不失客户的生意 | 不是"品牌"，是定价权 |
| 护城河 | 竞争结构带来的长期优势 | 常识以为是市场份额 |
| 市场先生 | 每天报价的躁郁症合伙人格 | 价格≠价值，情绪是报价的一部分 |
| 能力圈 | 只投自己真正懂的公司 | 常识以为"研究多=懂" |
| 安全边际 | 出价显著低于内在价值 | 防止"看错了也亏不多" |
| 永久性资本损失 | 本金再也回不来的损失 | 与"账面浮亏"完全不同，前者不可逆 |

### 核心命题
1. 你买的不是代码，是企业所有权的一部分。
2. 价格是你付出的，价值是你得到的；好价格来自恐慌。
3. 长期看，优秀企业+耐心持有＞频繁交易。
4. 能力圈外再便宜也不碰；宁错过不买错。
5. 不该做的事清单比该做的事清单更重要（不杠杆、不押注衍生品、不预测）。
6. 对大多数非专业人士：低成本宽基指数基金是最优解。

### 论证链
每条命题都有几十年的真实数字背书：每股账面价值年化增长、1965-2024 年伯克希尔 vs 标普 500 对比、具体买入案例（可口可乐/GEICO/苹果）、回购与并购决策记录。用"已发生的事实"而非"理论"论证。

## 3. 批判 (Critical) ★
### 作者的时代局限
- 美股 40 年长牛 + 长期低利率环境；"买入并永久持有"依赖美国国运向上。
- 保险浮存金（低成本杠杆）模式是伯克希尔独有优势，散户无法复制。

### 作者的立场盲点
- 集中持股带来巨大波动（伯克希尔多次回撤 50%+），书中对"回撤期间的心理承受"讲得少。
- 对指数基金的推荐与其"主动选股"实践存在内在张力（他承认大多数主动投资者跑输指数）。

### 未被证明的假设
- 假设长期内企业价值终将被市场认知；对"价值陷阱"（低估但永远不修复）着墨不足。
- 假设普通人有耐心在十年维度持有；行为金融证明多数人拿不住。

### 最强反对意见
过去 15 年成长股/科技股持续跑赢传统价值股，"价值投资已死"的质疑屡次出现；能力圈概念也常被滥用来拒绝学习。

> 以上批判会直接成为下游 skill 的 Boundary (B) 字段来源

## 4. 应用潜力 (Applicability)
### 可 skill 化的内容（最终用于 FundOS 基金助手）
- [ ] 能力圈与仓位上限：只持有自己懂的基金/资产，单品种上限
- [ ] 恐慌买入框架：大跌/危机时按计划分批加仓而非清仓
- [ ] 长期持有与复利：拿得住、少操作、用时间换收益
- [ ] 不做清单：不杠杆、不追热点、不满仓单一行业
- [ ] 普通人配置降级方案：宽基指数+定投+低费率（对应基金组合建议）

### 不适合 skill 化的内容
- 个股估值模型（DCF 实操）、并购套利、保险浮存金复制。

### 预估 skill 数量
约 4 个。

### 优先级排序（按"最能帮基金散户扭亏"）
1. 恐慌买入/逆势布局框架（解决"大跌割肉在底部"）
2. 能力圈与单品种仓位上限（解决"追热点重仓亏损"）
3. 不做清单（解决"频繁操作/追涨杀跌"）
4. 长期复利与定投纪律（解决"拿不住"）
