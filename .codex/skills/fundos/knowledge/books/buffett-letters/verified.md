# 阶段 1.5 — 三重验证筛选（《巴菲特致股东信》精选12封）

> 候选池：frameworks(10) + principles(12) + cases(10) + counter-examples(10) + glossary(8) = 50 条 → 去重合并为 11 个方法论单元 → 三重验证后通过 8 个。

## 通过单元（将进入阶段 2 构造 skill）

### b01 价值估值：以内在价值为标尺
- type: framework
- 来源候选: f01, f02, f03, g01, g04
- V1_cross_domain: ✅ 1984(账面vs内在)、1989(DCF定义)、1993(内在价值vs账面价值)、2016(长期向内在价值靠拢) 多封信独立印证。
- V2_predictive_power: ✅ 新问题"净值涨了20%的基金是不是好基金？"→ 推导：净值涨跌≠价值创造，要看底层资产现金流；主动基金须用费后长期收益证明价值。
- V3_exclusivity: ✅ "账面价值与内在价值在多数公司几乎无关"打破只看净值的散户习惯。

### b02 安全边际：好货打折才买
- type: framework
- 来源候选: f05, p02, p08, x08, f08
- V1_cross_domain: ✅ 1977(碎股折价)、1984(以买整家标准买碎股)、1997(安全边际被侵蚀警告)、2008(价格是你付的价值是你得的) 多信印证；x08 价值陷阱反例。
- V2_predictive_power: ✅ 新问题"板块跌了40%要不要抄底？"→ 推导：先确认是不是好资产，再看价格是否显著低于内在价值区间；便宜≠安全边际。
- V3_exclusivity: ✅ "价格是你付出的，价值是你得到的"+"困境反转很少反转"——反直觉，直接对抗散户捡便宜心理。

### b03 市场先生与恐慌买入
- type: framework
- 来源候选: f04, f07, p03, g06, c01, c02, x05
- V1_cross_domain: ✅ 1987(市场先生寓言+暴跌)、2008(悲观是朋友、145亿买入)、2016(广泛恐惧是朋友)、1997(鸭子比喻) 多信印证。
- V2_predictive_power: ✅ 新问题"大跌当天要不要清仓？"→ 推导：区分广泛恐惧(机会)与个人恐惧(敌人)；先查现金与加仓清单，按计划执行而非情绪。
- V3_exclusivity: ✅ "恐慌时用大盆而非茶匙接金子"与"个人恐惧是无根据的敌人"是差异化操作化框架。

### b04 能力圈：只买看得懂的
- type: framework
- 来源候选: f06, p07, x06(部分)
- V1_cross_domain: ✅ 1977(四重筛选第一是看得懂)、1987(技术太高不买)、1989(圈外错过不是罪)、1993(只做简单案例) 多信印证。
- V2_predictive_power: ✅ 新问题"AI主题基金很火要不要买？"→ 推导：若无法评估其底层资产的长期现金流则归入能力圈外；宁错过不买错。
- V3_exclusivity: ✅ "圈外错过不是罪，圈内犹豫(thumb-sucking)同样致命"双面框架，非普通常识。

### b05 长期持有三条件与复利
- type: framework
- 来源候选: f09, p01, p06, c09, c10
- V1_cross_domain: ✅ 1987(持有到永远的三条件)、1989(时间是优秀企业的朋友)、2022(可口可乐30年、杂草枯萎鲜花绽放)、1977(用ROE衡量) 多信印证。
- V2_predictive_power: ✅ 新问题"盈利30%的基金要不要卖？"→ 推导：按三条件体检(企业回报/管理层/估值)，三条都成立则持有，不因涨多卖。
- V3_exclusivity: ✅ "卖出理由从来不是涨多了或拿久了"+"You can't go broke taking a profit 是华尔街最蠢格言"反直觉。

### b06 仓位框架：分散还是集中，取决于认知
- type: framework
- 来源候选: f10, p09, p10, g08, c08, x07
- V1_cross_domain: ✅ 1993(know-nothing vs know-something)、1997(过度分散损害结果)、2016(指数基金赌局)、2005(帮手吃掉20%) 多信印证。
- V2_predictive_power: ✅ 新问题"持有8只主题基金算分散吗？"→ 推导：伪分散(同涨同跌的同类资产)不降低风险；普通人应低费率宽基指数，专业者集中。
- V3_exclusivity: ✅ "笨钱承认局限就不再笨"+"集中可能降低风险"反分散教条。

### b07 不做清单：杠杆、衍生品、复杂结构与预测
- type: principle
- 来源候选: p04, p05, x01, x02, x03, x04, x07(部分), x10
- V1_cross_domain: ✅ 1993(99:1也不赌)、2005(乘以零等于零)、2008(衍生品危险)、2022(芒格论杠杆)、1979(通胀固收) 多信印证。
- V2_predictive_power: ✅ 新问题"带杠杆的ETF值得买吗？"→ 推导：触发不做清单第一条，一票否决，无需论证。
- V3_exclusivity: ✅ "一串漂亮数字乘以零等于零"+"预测比无用更糟"是鲜明差异化断言。

### b08 及时纠错：拖延认错是最大罪过
- type: principle
- 来源候选: p11, x06, c03
- V1_cross_domain: ✅ 2005(dithering)、2008(吮拇指+ConocoPhillips认错)、2024(头号罪过) 多信印证。
- V2_predictive_power: ✅ 新问题"持仓逻辑被证伪了但还在亏损，要不要等回本？"→ 推导：证伪即触发纠错，越拖成本越高；止损/换仓是纪律不是认输。
- V3_exclusivity: ✅ "问题不会因被希望消失而消失，需要行动，无论多不舒服"把纠错升维为头号纪律。
