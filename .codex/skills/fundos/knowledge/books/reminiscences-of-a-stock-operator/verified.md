# 阶段 1.5 — 三重验证筛选（《股票大作手回忆录》）

> 候选池：frameworks(10) + principles(12) + cases(10) + counter-examples(10) + glossary(14) = 56 条 → 去重合并为 14 个方法论单元 → 三重验证后通过 7 个。

## 通过单元（将进入阶段 2 构造 skill）

### r01 趋势跟随：最小阻力线与关键点
- type: framework
- 来源候选: f01, f02, p02, p08, p01（支持句）
- V1_cross_domain: ✅ 第10-11章小麦$1.20案例；第8章Reading 111→92；第14章小麦/棉花战役；第10章"窄幅横盘不预测"——至少4个独立语境。
- V2_predictive_power: ✅ 新问题"基金组合里的震荡板块要不要动？"→ 推导：方向未明不操作，等突破区间边界确认，避免两头挨打。
- V3_exclusivity: ✅ 反直觉核心——"不预测价格目标，等市场自我定义方向"，与散户抄底摸顶习惯正相反。
- 备注: p01"市场只有一边：正确的一边"作为本单元总纲引用。

### r02 右侧建仓：试探仓 + 金字塔加仓，绝不摊平
- type: framework/rule
- 来源候选: f03, p07, p06, c05
- V1_cross_domain: ✅ 第11章"先买五分之一、首仓盈利才加仓"；第7章"初始交易后没有盈利就不加"；第13章"卖掉亏损的、拿住盈利的"；c05 Reading 试探做空案例。
- V2_predictive_power: ✅ 新问题"基金被套了该不该补仓摊薄成本？"→ 推导：摊平=放大错误仓位的暴露，正确做法是只在右侧信号确认后加仓或止损。
- V3_exclusivity: ✅ 与普通人"越跌越买"完全相反，是最反直觉的仓位规则之一。
- 备注: 基金场景映射为"分批申购/定投+右侧加码"。

### r03 止损即认错（亏损不是错误，不认错才是）
- type: rule
- 来源候选: f04, p05, x01, x10, c10
- V1_cross_domain: ✅ Anaconda 案例"想走就走"；第9章 1907 恐慌"无麻醉总截肢"；第17章 5万包棉花拖延止损亏25万；第10章 hope 警告。
- V2_predictive_power: ✅ 新问题"浮亏10%的基金要不要等回本？"→ 推导：止损纪律=用规则对抗 hope，达到阈值机械离场，不因"等反弹"延期。
- V3_exclusivity: ✅ "亏损不是错误，不认错才是"把止损从工具升维为生存哲学，含反转句式，非普通常识。
- 备注: 基金映射——预先设定单基金/单笔亏损阈值，机械执行，与交易复盘解耦。

### r04 拿住盈利（看对+拿住才赚大钱）
- type: principle
- 来源候选: f05, p03, p04, p11, x06, c03
- V1_cross_domain: ✅ 老火鸡 Partridge"这是我的位置"；第5章"牛市要坐着不动"；作者空头巨仓浮盈回吐一半不动摇；x06"4点利润卖飞牛市"反例。
- V2_predictive_power: ✅ 新问题"基金盈利15%要不要止盈落袋？"→ 推导：先判断趋势是否终结，而非固定点数；趋势未破则持有，破位才走。
- V3_exclusivity: ✅ "看对方向的人很多，看对又拿住的人极少"是差异化断言，直击散户过早止盈通病。
- 备注: 与 r03 构成"截断亏损、让利润奔跑"的对称纪律。

### r05 独立判断与防消息陷阱
- type: framework
- 来源候选: f07, p09, p12, x02, x03, x04, x05, c04, c07, c08
- V1_cross_domain: ✅ Percy Thomas 棉花局；Saratoga UP 权威朋友劝反手；Williamson 人情绑架；tips 上瘾者——4个独立大案例。
- V2_predictive_power: ✅ 新问题"券商/大V喊单该不该跟？"→ 推导：靠别人消息买就得靠别人消息卖，卖点失控→决策必须回到自身可复核证据。
- V3_exclusivity: ✅ "依赖别人买入=把资金命运交给对方"是反常识的决策独立论证。
- 备注: 与 EPD 的"从众/叙事检验"构成姊妹单元。

### r06 价格行为优先于解释（信息不对称）
