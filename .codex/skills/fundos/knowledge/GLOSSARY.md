# FundOS 知识库 — 统一术语表 (GLOSSARY)

> 来源：三本已蒸馏书籍的 glossary 候选池（阶段 1.5 降级保留）。术语按"作者原义"收录，与常识用法区分。
> 用途：技能写作与基金分析时的共同语言；防止"泡沫/杠杆/止损"等词被口语化误用。

## 一、《股票大作手回忆录》(Livermore) 术语

| 术语 | 作者的定义 | 与常识的差异 | 关联技能 |
|------|-----------|--------------|---------|
| 最小阻力线 (line of least resistance) | 价格朝阻力最小的方向运行，等市场自我定义方向再行动 | 常识想"预测方向"，作者是"等方向自己走出来" | trend-following-minimum-resistance |
| 关键点 (pivotal point，原文表述) | 突破关键价位后的确认点，是加仓/止损的触发器 | 不是"预测的顶底"，是"市场确认的标记" | trend-following-minimum-resistance |
| 金字塔加仓 (pyramiding) | 首仓盈利后才加仓，越加越少；亏损摊平是自杀 | 常识"越跌越买摊低成本"，作者"只给赢家加仓" | right-side-entry-pyramid |
| 拿住 (sitting tight) | 看对方向后坐着不动，让利润奔跑 | 常识"落袋为安"，作者"早卖=看对却赚不到" | hold-winners |
| 小道消息 (tips) | 靠别人消息买=把卖点也交给别人，命运失控 | 常识"消息=信息优势"，作者"消息=亏损来源" | independent-judgment |
| 内幕买盘 (inside buying) | 内部人真实买入是最强信号；没有就是没有 | 常识相信内幕新闻，作者只看可观测行为 | price-action-first |
| 止损单 (stop-loss order) | 认错的工具，亏损不是错误，不认错才是 | 常识把止损当"割肉痛苦"，作者当"生存纪律" | stop-loss-admission |
| 卖空 (short selling) | 与多头对称的立场，同样需要趋势确认 | 常识妖魔化卖空，作者视之为普通交易 | price-action-first |
| 保证金/杠杆 (margin) | 杠杆放大盈利也放大毁灭，破产的人多是保证金交易 | 常识只看到杠杆的进攻面 | leverage-amplifier / do-not-list |
| 韭菜 (sucker) | 永远接最后一棒、被反复收割的公众 | 常识指"新散户"，作者指"行为模式" | herd-contagion-check |
| 华尔街没有新鲜事 | 人性不变，历史反复重演 | 常识以为"这次不一样" | mania-cycle-map |

## 二、《巴菲特致股东信》(Buffett) 术语

| 术语 | 作者的定义 | 与常识的差异 | 关联技能 |
|------|-----------|--------------|---------|
| 内在价值 (Intrinsic Value) | 企业未来现金流的折现值，唯一合理的价值标尺 | 常识用净值/账面价值替代，二者常无关 | intrinsic-value-ruler |
| 市场先生 (Mr. Market) | 市场是情绪化的报价仆人，不是定价导师 | 常识把市场报价当"真相" | mr-market-panic-buying |
| 护城河 (Moat) | 长期资本回报率持续高于同行的结构性优势 | 常识把"品牌/规模"当护城河，作者看ROE证据 | hold-three-conditions |
| 透视盈余 (Look-Through Earnings) | 把持股公司盈利按比例计入，而非只看分红 | 常识只盯报表净利润 | intrinsic-value-ruler |
| 浮存金 (Insurance Float) | 先收保费后付赔款的低成本资金 | 常识视为负债，作者视为免费杠杆 | do-not-list |
| 回购 (Stock Repurchases) | 仅当价格低于内在价值时回购才创造价值 | 常识把回购一律当利好 | margin-of-safety |
| 生意特许权 (Franchise) | 拥有定价权、可抗通胀的生意 | 常识把"大公司"当特许权 | circle-of-competence |
| 低成本指数基金 | 承认无知的投资者最好的选择 | 常识以为"买基金=专业管理" | position-size-framework |

## 三、《非同寻常的大众幻想与群众性癫狂》(Mackay) 术语

| 术语 | 作者的定义 | 与常识的差异 | 关联技能 |
|------|-----------|--------------|---------|
| 狂热 (mania) | 全民参与的、脱离价值的集体追逐 | 不是"涨得猛"，是"人人都在谈" | mania-cycle-map |
| 泡沫 (bubble) | 价格与价值彻底脱钩且无真实回报支撑 | 事后才被确认，事前只看到"新范式" | mania-cycle-map |
| 投机 (speculation) | 赌"别人会出更高价"，与价值无关 | 常识把投机当投资 | narrative-news-check |
| 轻信 (credulity) | 因权威与叙事而放弃独立核实 | 常识归因"贪婪"，作者归因"模仿" | herd-contagion-check |
| 认购 (subscriptions) | 发行制度本身被操纵为抬价工具 | 常识视为中性流程 | mass-participation-top |
| 癫狂 (frenzy) | 传染性集体状态，贵族与平民无异 | 常识当个人情绪词 | herd-contagion-check |
| 赌博精神 (gambling spirit) | 把交易变成纯涨跌对赌，得不到价值支撑 | 常识限定为个人恶习，作者上升为宏观规律 | leverage-amplifier |
| 集体错觉 (delusion) | 由模仿与从众传播的群体性错误 | 心理学指个人妄想，作者强调 popular | narrative-news-check |
| 全民参与信号 | 从不碰金融的人也进场 = 接盘者枯竭 | 常识把"人气高"当利好 | mass-participation-top |
| 杠杆/信用扩张 | 狂热放大器也是崩溃放大器 | 常识只看进攻面 | leverage-amplifier |

## 四、FundOS 实操术语（项目内部）

| 术语 | 含义 | 使用位置 |
|------|------|---------|
| 主线 | 全市场资金持续流入、连续走强的方向（涨幅+资金+持续性三合一） | sector-rotation-detector |
| 破圈度 | 从不理财的人群开始讨论某板块/基金的程度 | mass-participation-top |
| 右侧确认 | 趋势方向被价格行为确认后再行动（突破+站稳） | right-side-entry-pyramid |
| 回本数学 | 亏10%需涨11.1%、亏20%需涨25%、亏30%需涨42.9% | stop-loss-admission / timely-correction |
| 分批节奏 | 调仓每次≤20%、分批3次、记录逻辑 | 所有操作类技能 E 段 |
| 叙事三层检验 | 利好拆成：事实 / 叙事 / 杠杆 | narrative-news-check |
