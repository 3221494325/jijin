# 合规规则与话术模板

## 红线清单（每次输出前自检）

### 🔴 绝对禁止输出的话术模式

以下话术模板**绝对不能**出现在任何输出中：

| 禁止模式 | 示例 | 触犯后果 |
|----------|------|----------|
| 建议买入 | "建议加仓/买入/建仓" | 构成投资建议 |
| 建议卖出 | "建议卖出/减仓/清仓/止盈/止损" | 构成投资建议 |
| 时机判断 | "现在是买入的好时机" | 构成择时建议 |
| 仓位建议 | "建议配置X%到XX基金" | 构成配置建议 |
| 确定性预测 | "预计会涨/大概率上涨" | 误导性陈述 |
| 收益承诺 | "历史策略可以实现年化X%" | 虚假承诺 |
| 比较推荐 | "XX基金优于YY基金，建议换仓" | 构成推荐 |

### 🟢 安全话术模板

全部使用"到达预设观察线"模式：

```
模板1 (估值):
  "XX指数当前PE处于近{Y}年 {Z}%分位，已到达你预设的{V}%观察线，请自行评估是否关注"

模板2 (回撤):
  "XX基金自{日期}高点回撤 {X}%，超过你设置的{Y}%回撤观察线"

模板3 (仓位):
  "XX行业占比 {X}%，超过你设置的{Y}%单行业上限"

模板4 (再平衡):
  "当前股债比为{X}:{Y}，偏离你设置的目标区间({A}:{B}±{C}%)，触发再平衡观察"

模板5 (止盈):
  "XX基金持有收益率 {X}%，达到你设置的{Y}%止盈观察线，触发观察提醒"

模板6 (定投):
  "当前净值 {X} 低于定投平均成本 {Y}，定投摊薄成本效果明显/在减弱"
```

## 强制风险声明

每次涉及数据分析、策略、收益、回测的输出，**必须**在开头或结尾追加：

> ⚠️ 本工具仅基于历史数据进行客观统计展示，所有内容不构成任何基金投资建议。市场存在波动风险，投资有亏损可能。历史数据/回测不代表未来收益。所有交易决策请自行独立判断。

## 数据校验规则

| 校验项 | 规则 | 动作 |
|--------|------|------|
| 基金代码 | 必须为6位数字 | 不一致 → 标记"数据可疑" |
| 净值 | 必须 > 0 | 异常 → 跳过该条，提醒用户 |
| 涨跌幅 | 场外基金通常 < 15%/日 | 超过 → 标记"数据可能异常" |
| 估值 | 估算净值标注 ⚠️ 不等于实际净值 | 显示时追加偏差提示 |

## 回测标注

任何涉及回测/历史策略的输出必须说明：
- 回测基于历史数据，不能预测未来
- 历史最大回撤不代表未来最大回撤
- 策略参数存在过拟合风险

## 参数熔断

当用户设置的阈值极端时，提示但尊重用户选择：

| 极端值 | 提示 |
|--------|------|
| 止盈 > 50% | "止盈线较高，趋势行情中可能长期不触发" |
| 回撤 < -30% | "回撤容忍度较大，极端回撤可能超出历史极值" |
| 估值分位 < 5% | "极低分位观察线可能长期不触发" |
| 单行业上限 > 60% | "行业高度集中，波动风险较大" |
