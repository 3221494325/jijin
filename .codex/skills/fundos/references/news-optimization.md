# 新闻采集优化方案 v2.0

## 一、当前问题诊断

| 问题 | 现状 | 影响 |
|------|------|------|
| 数据源太少 | 仅东方财富/财联社/新浪3个 | 视角单一，漏掉关键信息 |
| 关键词太粗 | 每板块4-5个泛词 | 搜到大量无关内容，遗漏精准消息 |
| 维度单一 | 仅新闻标题 | 缺基金公告/宏观/资金流/海外联动 |
| 情绪分类粗糙 | 简单关键词计数 | 误判率高 |
| 无关联度排序 | 所有结果平铺 | 用户需手动筛选 |
| 无定时采集 | 手动触发 | 错过盘中消息 |

## 四、关键词分层策略

每个板块三层关键词：核心词（高精度）+ 扩展词（中精度）+ 关联词（覆盖）

### 示例：半导体板块

```
核心词 (必须命中):
  "半导体 政策" / "芯片 制裁" / "光刻机 突破" / "晶圆 涨价"

扩展词 (提升覆盖):
  "集成电路" / "先进封装" / "第三代半导体" / "EDA"

关联词 (交叉板块):
  "AI芯片" (跨AI) / "汽车芯片" (跨新能源) / "存储芯片"
```

## 五、关联度打分

每条新闻对持仓基金的影响程度：

```
直接相关 (3分): 新闻明确提到持仓基金/重仓股/所属指数
板块相关 (2分): 新闻涉及基金所属行业板块
市场相关 (1分): 宏观/政策/海外影响整体市场
```

## 六、情绪分类升级

v1.0: 简单关键词计数
v2.0: 关键词加权 + 位置权重 + 否定词检测

```python
# 否定词检测
"不会下跌" → 实际偏多（"下跌"被"不会"否定）
"未能上涨" → 实际偏空（"上涨"被"未能"否定）

# 位置权重
标题关键词 ×3 / 首段关键词 ×2 / 正文关键词 ×1

# 标题情绪 > 正文情绪（标题决定读者第一印象）
```
